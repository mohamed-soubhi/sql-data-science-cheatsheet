# SQL for Data Science — Cheatsheet

> ✍️ **What this is:** a personal cheatsheet — **my own summary of what I
> learned** while completing the IBM course *"Databases and SQL for Data
> Science with Python"*. It started as my study notes from the course's
> video transcripts, which I reorganized, rewrote in my own structure, and
> condensed into a single interactive reference page.

A condensed, browsable cheatsheet: 29 lecture summaries plus a one-page
cheat card, all in a single interactive HTML page.

> **Live:** https://mohamed-soubhi.github.io/sql-data-science-cheatsheet/
> (also available locally as **`index.html`** — works completely offline,
> no external dependencies beyond fonts, which degrade gracefully).

## What's inside the page

- **30 browsable tabs** — one per course lecture, grouped by module, plus a topmost
  **Cheat Card** tab with the most-used syntax (SELECT skeleton, WHERE toolkit,
  JOIN families, DDL quick reference) and the top-10 habits from the whole course.
- **Keyword search** — filters lecture tabs by title and topic.
- Per-tab structure: one-line overview → runnable syntax → tips & tricks →
  best-use cases, with dialect notes (DB2 / MySQL / SQLite / …) where the
  course's examples were dialect-specific.
- **Light/dark theme** toggle (follows your system by default).

## Course map

| Module | Topics |
|---|---|
| 1 — Basics | Course overview, data/database/RDBMS definitions, DDL vs DML, relational & ER model |
| 2 — Data definition | CREATE TABLE, ALTER/DROP/TRUNCATE |
| 3 — DML & querying | INSERT, SELECT/WHERE, COUNT/DISTINCT/LIMIT, UPDATE/DELETE |
| 4 — Advanced querying | LIKE/BETWEEN/IN, ORDER BY, GROUP BY/HAVING, built-in functions, date-time functions |
| 5 — Multi-table | Sub-queries, multiple tables per query, JOINs (overview, inner, LEFT/RIGHT/FULL outer) |
| 6 — Python access | Python DB APIs, DB-API connections & cursors, SQL Magic, CSV loading tips, metadata catalogs, EDA with pandas/seaborn |
| 7 — Advanced server | Views, Stored Procedures, ACID Transactions |
